Tidak Ada Koneksi Internet

Sepertinya Anda sedang offline. Periksa koneksi internet Anda dan coba lagi.

Penyebab Umum & Solusi

Kemungkinan Penyebab:

  • ✗ WiFi atau data seluler tidak aktif
  • ✗ Router atau modem bermasalah
  • ✗ ISP sedang mengalami gangguan
  • ✗ Airplane mode aktif

Langkah Penyelesaian:

  1. 1. Periksa WiFi atau data seluler aktif
  2. 2. Restart router atau modem Anda
  3. 3. Matikan airplane mode jika aktif
  4. 4. Coba connect ke jaringan lain
Status Koneksi:
Offline

Panduan Troubleshooting Lengkap

🔌 Masalah WiFi

• Periksa apakah WiFi sudah aktif di device Anda

• Pastikan Anda terhubung ke jaringan yang benar

• Coba forget network dan connect ulang

• Restart router dengan cabut-colok power selama 30 detik

📱 Masalah Data Seluler

• Pastikan data seluler sudah diaktifkan

• Periksa apakah kuota masih tersedia

• Coba toggle airplane mode on/off

• Restart smartphone Anda

🖥️ Masalah Browser/Device

• Clear cache dan cookies browser

• Coba browser berbeda

• Update browser ke versi terbaru

• Restart device Anda
