429

Terlalu Banyak Permintaan

Anda telah mengirim terlalu banyak permintaan dalam waktu singkat. Mohon tunggu sebentar.

Kemungkinan Penyebab

  • • Rate limit telah terlampaui
  • • Terlalu banyak refresh atau request berulang
  • • Bot atau script otomatis terdeteksi
  • • API call melebihi quota yang diizinkan

Langkah Penyelesaian

  1. 1. Tunggu beberapa menit sebelum mencoba lagi
  2. 2. Kurangi frekuensi permintaan ke server
  3. 3. Periksa apakah ada script otomatis yang berjalan
  4. 4. Upgrade paket jika membutuhkan rate limit lebih tinggi

Waktu Tunggu: Biasanya 1-5 menit. Halaman akan otomatis refresh.
