422

Data Tidak Dapat Diproses

Data yang Anda kirim valid secara format, tetapi tidak dapat diproses karena kesalahan semantik.

Kemungkinan Penyebab

  • • Field wajib tidak diisi atau kosong
  • • Format data tidak sesuai (email, nomor telepon, dll)
  • • Nilai field di luar jangkauan yang valid
  • • Validasi business logic gagal

Langkah Penyelesaian

  1. 1. Periksa semua field wajib sudah terisi dengan benar
  2. 2. Verifikasi format data sesuai requirements
  3. 3. Pastikan tidak ada karakter atau nilai yang tidak valid
  4. 4. Perhatikan pesan error untuk detail spesifik
